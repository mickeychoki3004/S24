HAPPY 24TH BIRTHDAY WEBSITE ❤️

Files:
- index.html: website content
- style.css: design, layout and animations
- script.js: floating hearts, scroll reveals and confetti
- images/: your uploaded photos used by the website

Preview:
Open index.html in a browser. It is a static site and needs no backend or build step.

Deploy:
- Netlify: drag the entire extracted birthday_website folder into the deploy area.
- GitHub Pages: upload the folder contents to a repository and enable Pages.
- Any static hosting: upload index.html, style.css, script.js, and the images folder together.

You can edit the letter in index.html. Keep the image filenames inside images/ unchanged unless you also update the corresponding src paths in index.html.
